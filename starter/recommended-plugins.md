# 新手入门包 — 推荐插件清单

> 精选标准：已发布 npm、有 dsh-plugin topic、在 awesome-dsh-plugin 收录或由我们维护验证。按场景分组，装之前先想想你要解决什么问题。

## 第一组：刚开始（还没头绪）

| 插件 | 说明 | 装法 |
| --- | --- | --- |
| `dsh-starter-zh` | 新手引导：学习路径 + 自查清单（本入门包的插件形态） | `dsh plugin --profile <name> add dsh-starter-zh` |
| `dsh-recipe` | 场景配方：要整套环境时用它展开安装序列 | `dsh plugin --profile <name> add dsh-recipe` |
| `dsh-need-finder` | 用一句话需求匹配插件 | `dsh plugin --profile <name> add dsh-need-finder` |

## 第二组：专注与记忆

| 插件 | 说明 | 装法 |
| --- | --- | --- |
| `dsh-plugin-focus` | 专注板：跨会话钉住目标/约束/决策 | `dsh plugin --profile <name> add dsh-plugin-focus` |
| `dsh-native-memory` | 原生记忆：会话间长期记忆 | `dsh plugin --profile <name> add dsh-native-memory` |

## 第三组：安全与治理（企业/团队场景）

| 插件 | 说明 | 装法 |
| --- | --- | --- |
| `dsh-gov` | 治理套件：策略/合规/审计 | `dsh plugin --profile <name> add dsh-gov` |
| `dsh-audit` | 插件健康审计：体检已装插件 | `dsh plugin --profile <name> add dsh-audit` |
| `dsh-security-guard` | 安全守卫：安装前扫描 | `dsh plugin --profile <name> add dsh-security-guard` |

## 第四组：提效

| 插件 | 说明 | 装法 |
| --- | --- | --- |
| `dsh-feed` | 生态数据层：聚合插件/仓库/更新 | `dsh plugin --profile <name> add dsh-feed` |
| `dsh-insight` | 插件洞察：指南+配方+排行+审计 | `dsh plugin --profile <name> add dsh-insight` |
| `dsh-trend-radar` | 趋势雷达：生态趋势看板 | `dsh plugin --profile <name> add dsh-trend-radar` |

> 更多插件：翻 [awesome-dsh-plugin](https://github.com/awesome-dsh-plugin/awesome-dsh-plugin) 的 data/plugins/ 目录，或用 `dsh-need-finder` 按需求搜。
